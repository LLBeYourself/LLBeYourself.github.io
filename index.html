  • 为 dots.ocr 的 42 层 ViT 实现 SupportsEncoderCudaGraph：forward 拆成图外 metadata 准备与图内计算；cu_seqlens 在 CPU 上算好并按批补齐，max_seqlen 按档位取定值，图内没有 CPU 同步。

Mini-vLLM 多模态推理引擎2026.04 – 至今

学习型项目，参考官方 vLLM 实现

  • 调度：Continuous Batching + Chunked Prefill，按 token 预算混合调度；Decode 阶段使用 CUDA Graph。
  • 显存：Paged KV cache（Block Table、Slot Mapping）与 Prefix Caching（引用计数、LRU 淘汰）。
  • 多模态：适配 Qwen3-VL，包括 Encoder Cache、M-RoPE 三维位置编码和 DeepStack 视觉特征注入。
  • 并行：多进程 Worker + NCCL 张量并行，TP=2/4 与单卡逐 token 一致。
